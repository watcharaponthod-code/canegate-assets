# CaneGate — assets

รูปประกอบสำหรับหน้า Docker Hub และเอกสารของ **CaneGate**
ระบบตรวจรถบรรทุกอ้อยที่ลานชั่ง (กล้องด้านข้างตรวจอ้อย · กล้องด้านหน้าอ่านทะเบียน)

repo นี้เก็บเฉพาะไฟล์ภาพ ไม่มีซอร์สโค้ด

| ไฟล์ | คืออะไร |
|---|---|
| `banner.png` | แบนเนอร์โปรเจกต์ |
| `screen-live.png` | หน้าปฏิบัติงาน |
| `screen-modal.png` | หน้าต่างยืนยันรายคัน |
| `screen-stats.png` | สรุปกะ |
| `screen-records.png` | ประวัติรถ |
| `screen-sim.png` | โหมดจำลองทดสอบ |
| `screen-setup.png` | ตั้งค่ากล้อง |

อิมเมจบน Docker Hub: https://hub.docker.com/r/khawoat07/canegate
